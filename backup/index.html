NL-to-SQL Reporting Assistant
  • Built a full-stack app that converts plain-English business questions into T-SQL using a locally hosted LLM (Ollama), with a React UI showing results tables and the generated SQL.
  • Designed a schema-aware prompting layer with a curated catalog of reporting views, column descriptions, join rules and few-shot examples, so the model only sees approved data.
  • Enforced safe execution with sqlglot-based SQL validation (single SELECT, view whitelist), input guardrails, a read-only SQL Server login, query timeouts and row limits; logged every request to MongoDB for auditing and measured accuracy and latency on a golden question set to tune prompts.
AURELIS – Expense Anomaly Detector
  • Built a full-stack expense tracker that flags unusual spending with per-category z-score analysis, using each user's own past spending as the baseline, in a team of 3.
  • Moved the app from browser localStorage to a REST API (Node.js, Express, MongoDB Atlas) with an MVC structure, and kept the existing frontend working without a redesign.
  • Added secure accounts with bcrypt-hashed passwords and JWT login, and made sure users can only see or change their own data.
Smart IoT Heartbeat Monitoring System with Cloud Integration
  • Built an IoT health monitor using Arduino UNO, MAX30102 sensor, and ESP01 WiFi module to capture heart rate and SpO2 in real time.
  • Implemented concurrent data acquisition and streamed live vitals to ThingSpeak for remote monitoring and visualization.
