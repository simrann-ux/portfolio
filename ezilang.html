EziLang

Vocabulary that sticks.

ezilang.netlify.app

What makes daily vocabulary practice something you come back to?

EziLang is a responsive language learning platform built from scratch with HTML, CSS and JavaScript, featuring interactive UI components and continuous deployment on Netlify. No frameworks, no build step — just clean, semantic code and careful interaction design.

HTML5 CSS3 animations JavaScript (ES6+) Web Speech API Netlify CI/CD

Key Capabilities

Small details that make practice feel effortless.

3D flip cards

CSS perspective card flips with phonetic guides and situational example sentences on the back, so every word comes with context.

Native pronunciation

The browser's Web Speech synthesis reads each word aloud in Spanish, so learners hear the pronunciation instead of guessing from the phonetics.

Continuous deployment

Every push goes live through Netlify's CI/CD pipeline, and the fully responsive layout works the same on a phone in a queue as on a laptop at a desk.
