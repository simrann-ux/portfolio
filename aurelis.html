What counts as "unusual spending"? Unusual for you.

AURELIS is a full-stack expense tracker, built in a team of 3, that flags unusual spending with per-category z-score analysis. Each user's own past spending is the baseline — so a ₹2,000 dinner is normal for one person and an anomaly for another.

Node.js Express.js MongoDB Atlas JWT bcrypt REST / MVC

Where It Started

A browser-only tracker with everything in localStorage: one device, one user, no accounts, and data gone with a cleared cache.

Where It Ended Up

A REST API on Node.js, Express and MongoDB Atlas with an MVC structure, secure accounts, and per-user data isolation — with the existing frontend still working, unchanged.

How It Works

From a logged expense to a flagged anomaly.

01

Log expenses by category

Users record spending in categories like food, transport and shopping. Each entry lands in MongoDB under that user's account, building their personal history.

02

Build the personal baseline

For every category, AURELIS computes the mean and standard deviation of that user's own past spending. There are no global thresholds — your baseline is you.

03

Score every new expense

Each new entry gets a z-score against its category baseline. Spend far enough above your usual — like ₹8,900 on shopping when you average ₹600 — and the expense is flagged in the UI.

Engineering Highlights

The hard part was migrating without breaking anything.

localStorage to REST, no redesign

Moved the app from browser storage to a Node.js, Express and MongoDB Atlas API with an MVC structure, while keeping the existing frontend working throughout.

Secure accounts

Passwords are hashed with bcrypt and sessions use JWT login. Authorization checks make sure users can only ever see or change their own data.

Built in a team of 3

Split across frontend, API and data layers with Git-based collaboration — agreeing on contracts first so the pieces met in the middle.
